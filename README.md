# 📊 Simulador de Investimentos em Fundos Imobiliários

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio da **Digital Innovation One (DIO)**, com o objetivo de aplicar conhecimentos em Excel na criação de uma ferramenta prática para simulação de investimentos em Fundos Imobiliários (FIIs).

A planilha permite realizar simulações considerando diferentes variáveis, como valor do aporte mensal, período de investimento e taxa de rendimento. A partir dessas informações, são calculados o patrimônio acumulado e uma estimativa dos dividendos mensais.

Além disso, o projeto apresenta diferentes perfis de investidor e uma sugestão de distribuição dos investimentos entre categorias de Fundos Imobiliários.

---

## 🎯 Objetivo

Desenvolver uma ferramenta em Excel capaz de auxiliar usuários na simulação de investimentos em Fundos Imobiliários, proporcionando uma visão mais clara sobre o potencial crescimento do patrimônio ao longo do tempo.

O projeto busca demonstrar a aplicação prática de conceitos financeiros e funcionalidades do Excel para automatizar cálculos e facilitar a análise de diferentes cenários de investimento.

---

## ⚙️ Funcionalidades

A ferramenta permite:

- 💰 Definir o valor do aporte mensal;
- 📅 Escolher o período de investimento;
- 📈 Simular o crescimento do patrimônio ao longo do tempo;
- 💵 Calcular uma estimativa de dividendos mensais;
- 📊 Comparar diferentes cenários de investimento;
- 👤 Selecionar diferentes perfis de investidor;
- 🏢 Visualizar uma sugestão de distribuição entre categorias de Fundos Imobiliários;
- 🔢 Automatizar cálculos financeiros por meio de fórmulas do Excel.

---

## 🧮 Como funciona a simulação

O usuário informa os principais dados para realizar a simulação:

### 💵 Valor do aporte mensal

Representa o valor que será investido mensalmente.

### ⏳ Período de investimento

Define durante quanto tempo os investimentos serão realizados.

### 📈 Taxa de rendimento

Utilizada para estimar o crescimento do patrimônio ao longo do período selecionado.

### 💰 Rendimento da carteira

Utilizado para realizar uma estimativa dos dividendos mensais que podem ser gerados pelo patrimônio acumulado.

Com base nessas informações, a planilha realiza automaticamente os cálculos e apresenta os resultados da simulação.

---

## 👤 Perfis de Investidor

O simulador também considera diferentes perfis de investidor:

### 🟢 Conservador

Perfil voltado para investidores que buscam uma maior estabilidade em seus investimentos.

### 🟡 Moderado

Perfil que busca equilibrar estabilidade e potencial de crescimento.

### 🔴 Agressivo

Perfil voltado para investidores que aceitam uma maior exposição ao risco em busca de maiores possibilidades de retorno.

Cada perfil possui uma sugestão de distribuição entre diferentes categorias de Fundos Imobiliários.

---

## 🏢 Categorias de Fundos Imobiliários

A ferramenta apresenta uma sugestão de distribuição entre diferentes tipos de FIIs, como:

- Fundos de Papel;
- Fundos de Tijolo;
- Fundos Híbridos;
- Fundos de Fundos (FOFs);
- Fundos de Desenvolvimento;
- Fundos de Hotelaria.

A distribuição pode variar de acordo com o perfil de investidor selecionado.

---

## 📊 Cenários de Investimento

A planilha permite visualizar projeções para diferentes períodos de investimento, possibilitando analisar o impacto dos aportes mensais e dos rendimentos ao longo do tempo.

Entre os cenários apresentados estão projeções de:

- 2 anos;
- 5 anos;
- 10 anos;
- 20 anos;
- 30 anos.

Dessa forma, o usuário pode observar como o longo prazo pode influenciar na evolução do patrimônio.

## 🚀 Como utilizar

1. Faça o download do arquivo Excel disponível neste repositório;
2. Abra a planilha no Microsoft Excel;
3. Informe o valor que deseja investir mensalmente;
4. Selecione o período desejado para a simulação;
5. Analise os resultados apresentados;
6. Escolha um perfil de investidor para visualizar uma sugestão de distribuição entre categorias de FIIs.

Os cálculos serão realizados automaticamente pela planilha.

---

## ⚠️ Aviso Importante

Este projeto possui finalidade exclusivamente educacional.

As simulações apresentadas são baseadas em valores e taxas informadas na planilha e não representam garantia de rentabilidade futura.

O conteúdo não deve ser considerado como recomendação de investimento ou orientação financeira.

Antes de realizar qualquer investimento, é importante estudar os ativos e considerar seu perfil de investidor e seus objetivos financeiros.
